# Email icon assets

Drop PNG icon files here to replace the emoji in the quotation email with your
exact design icons. Each file is attached to the email and referenced by
`cid:ic_<name>`. **If a file is missing, that icon falls back to an emoji** — so
the email always renders even before you add any files.

Use small, square PNGs (recommended 48×48 or 64×64, transparent background,
navy/monochrome to match the design).
